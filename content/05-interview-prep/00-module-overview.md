# Module 5 — Interview Preparation

## Why this module comes last

Knowing the answer and being able to say it under pressure are different skills. Everything before
this module trained the first. This module trains the second: rehearsal, system design, portfolio,
and the mock-interview protocol that ties it all together.

The four question-bank lessons (L97–L100) are drawn directly from the first four modules — closures,
the event loop, generics, `useEffect`, caching. They are not new material. They are the same material
under exam conditions, because **rehearsal is the skill**. Then the module moves past answering
questions to the parts of the process most candidates never practise: coding under a timer (L101),
designing out loud (L102), the projects you walk in with (L103), and running the whole interview as a
repeatable protocol (L104).

## Module map

- **M11 · Production Concerns (L97–L102)** — shipping, not just reading.
  Top JS/TS/React/Next.js interview questions, common coding tasks, frontend system design.
- **M12 · Interview Ready (L103–L104)** — the work you bring and the way you perform.
  Portfolio projects, mock interview playbook.

## How to study each lesson

1. **Say the answers out loud.** Reading them silently trains recall; saying them trains delivery.
   Record yourself once — the playback is uncomfortable and essential.
2. **Answer before you peek.** The question-bank lessons are flip cards: answer first, then reveal.
   Wrong answers are the highest-value moments.
3. **Do the exercise in a file, not in your head.** Run it with
   `node exercises/05-interview-prep/<name>.js`.
4. **Do L101–L104 with a timer.** Coding tasks and system design are graded on process under
   pressure; only a timer reproduces the pressure.

## Prerequisites

Modules 1–4 complete. Every lesson in this module references earlier lessons by number — if one
feels out of reach, the prerequisite lesson is named in the text.
