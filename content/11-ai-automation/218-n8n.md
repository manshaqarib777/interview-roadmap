## 4. How It Works — The Nodes, the AI, the Fit, the Limits

- **The nodes (L218).** A workflow is a canvas of nodes: trigger nodes (L220), integration nodes (L223–227), logic nodes (IF, switch, L230), and the AI node (L163). Each node is a step with a contract (L217) — input, transform, output (L163).
- **The AI node (L163).** The model call inside the workflow: a prompt, a model, and a schema (L143) — extract, classify, summarize, draft (L163). The AI node is the L163 station on the L217 line (L218).
- **The fit (L230).** Integration-heavy workflows with standard shapes — trigger, extract, gate, post — built in hours (L217): the visual canvas (L218), the 400+ integrations (L223–227), and self-hosting (L288). The fastest L217 implementation for the standard line (L230).
- **The limits (L230).** Complex state (L207), heavy branching (L215), and custom logic where code beats nodes (L230): a long-running workflow with checkpoints (L207), a graph-shaped flow (L215), or business logic beyond IF nodes (L230) — those are the custom build's territory (L230).

> [!NOTE]
> **n8n is a tool for the L217 unit — not the L230 platform's replacement (L230).** The senior rule: n8n implements the *workflow* (L217) — the standard-shaped line — beautifully (L218). But the platform (L230) — the events (L220), queues (L222), approval gates (L228), and recovery (L232) — is an architecture that n8n supports but doesn't replace (L230). The decision is by shape: standard workflows, integration-heavy → n8n (L218); custom state, branching, or scale → the custom build (L230). The tool follows the architecture, not the other way around (L230).

- **No checkpoints (L228).** Consequential steps in the canvas without the human gate (L208) — the trust (L324) gone (L218).

    // THE GATE (L208, L228) — the human checkpoint

    // INTEGRATION (L227) — the world

  ],
  connections: {
    trigger: { main: [[{ node: 'extract' }]] },        // the skeleton (L199)
    extract: { main: [[{ node: 'approve' }]] },        // the gate (L208)
    approve: { main: [[{ node: 'post' }]] },
  },
};
